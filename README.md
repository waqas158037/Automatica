# Automatica Website

Static company website for **Automatica** (Lahore). Plain HTML, CSS and JavaScript, generated by a tiny Node script with no dependencies.

## Run locally
```bash
npm run build        # writes the site to /public
npm run dev          # build + serve on http://localhost:3000
```

## Deploy on Vercel
1. Push this repo to GitHub.
2. In Vercel: **Add New → Project → Import** this repo.
3. Leave the settings as they are (`vercel.json` already sets build command `node scripts/build.mjs` and output folder `public`). Click **Deploy**.

Every push to `main` redeploys automatically.

## Editing content
- All text, products, solutions, projects, contact details: `scripts/data.mjs`
- Page layouts: `scripts/build.mjs`
- Styles and animations: `assets/css/style.css`
- Interactions (slider, sticky header, menu, counters, reveal animations, quote list): `assets/js/main.js`

Run `npm run build` after editing (Vercel does this on deploy too).

## Images
All images are generated SVG illustrations (no licensed stock photos are shipped).
To use a real photo, save it as JPG in `static/images/` with the same name as the generated file, e.g.

- `static/images/hero-1.jpg`, `hero-2.jpg`, `hero-3.jpg` (home slider, 1920×900)
- `static/images/product-<slug>.jpg` (square, e.g. `product-dock-leveler.jpg`)
- `static/images/solution-<slug>.jpg`, `project-1.jpg` … `project-12.jpg`
- `static/images/service-team.jpg`, `about-service.jpg`, `range-bg.jpg`, `banner-doors.jpg`, `banner-entrances.jpg`, `page-banner.jpg`

The build picks up the JPG automatically instead of the SVG.

## Forms
This is a static site, so the contact, quote and newsletter forms open the visitor's email app addressed to `support@automatica.com`. To receive submissions directly, connect a form service (Formspree, Web3Forms, etc.) later.
